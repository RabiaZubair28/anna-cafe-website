# Anna Cafe React + Tailwind Website

Updated version with:
- Transparent/cutout-style product images for every unique menu product.
- Individual product image mapping across menu, gallery, products, order tray, and cart/tray thumbnails.
- Video-style drag and drop order tray.
- Dark bottom tray bar restored.
- Menu pages displayed uncropped.

Run locally:

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
